# Temptation Website

This is a free static website for `temptations137`.

## Edit content

Update everything from [site-data.js](/c:/Users/91636/OneDrive/Desktop/temptation/site-data.js):

- `business.instagramUrl` and `business.instagramHandle` for Instagram
- `business.whatsappNumber` to turn on one-tap WhatsApp ordering
- `menu` to add or change desserts
- `newDrops` to show next-week launches
- `videos` to add or replace website videos
- `reviews` for customer reviews
- `contactDetails` for contact information

## Add a new dessert

1. Add the dessert image into `assets/images/`
2. Add a new object inside `menu`
3. Add the same dessert inside `newDrops` if you want it highlighted as a new launch

## Add a video

1. Put the video file into `assets/videos/`
2. Update the matching object inside `videos`
3. Refresh the page

## Open locally

Open [index.html](/c:/Users/91636/OneDrive/Desktop/temptation/index.html) in a browser.

## Deploy free

You can host this free on GitHub Pages, Netlify, or Vercel because it is a plain static site.
